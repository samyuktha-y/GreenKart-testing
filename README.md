# 🛒 GreenKart Automation Suite

This is an end-to-end automation framework for testing the [GreenKart](https://rahulshettyacademy.com/seleniumPractise/#/) shopping site using **Python**, **Selenium**, and **pytest**.

---

## 🚀 Features

- 🔍 Search for items (e.g., cucumber, tomato, raspberry)
- ➕ Add products to cart
- 🛒 Proceed to checkout
- ✅ Parametrized testing with Pytest
- 📄 HTML test reporting via pytest-html

---

## 🧰 Tech Stack

- Python 3.13+
- Selenium WebDriver
- Pytest
- Pytest HTML plugin

---
